# Proposals

Draft design documents for larger features, kept out of `docs/` so they are not
built into the public documentation site.

A proposal describes the problem, the options that were considered, and a
recommendation. It is not a promise that something will be built, and it stops
being authoritative once the feature ships — at that point the real
documentation lives in `docs/guides/`.
